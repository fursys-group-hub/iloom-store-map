### 치명 · 도커 설정(Dockerfile) 만들기
아래 글을 그대로 복사해 AI 도구에 붙여넣으면 이 문제를 고쳐줍니다.
```
이 프로젝트는 index.html 을 메인으로 하는 정적 웹페이지야(같은 폴더의 *.js 데이터 파일들을 함께 불러와). crawlers/ 와 scripts/ 의 Node.js 파일들은 GitHub Actions 에서만 도는 데이터 수집·갱신용이라 웹 서버에는 들어가면 안 돼.

사내 서버(단일 컨테이너)에 올릴 수 있도록, 레포 루트에 표준 Dockerfile 을 만들어줘. 요구사항:
- nginx 같은 가벼운 정적 웹서버로 현재 폴더의 정적 파일(index.html, iloom_store_map.html, *.js, district_boundaries.js 등)을 그대로 서빙
- node_modules, crawlers/, scripts/, .git, .github 는 이미지에 넣지 말 것(.dockerignore 도 함께 만들어줘)
- 80 포트로 listen 하고 Dockerfile 에 EXPOSE 80 명시
- HEALTHCHECK 도 넣어줘(루트 / 응답 확인)
만들고 나서 어떻게 쓰는지 한 줄로 알려줘.
```
